# FileBase — Android 文件服务器

把 Android 手机变成全功能网页文件管理器。连接手机热点的任何设备，无需安装 App，打开浏览器即可浏览、上传、下载、编辑 `/sdcard` 内的所有文件。

[English Documentation](README.md)

---

## 功能

| 类别 | 说明 |
|------|------|
| **浏览** | 目录列表、可排序列（名称/大小/日期）、面包屑导航、实时搜索过滤 |
| **上传** | 按钮多选上传、拖放上传带进度条、二进制文件安全 |
| **下载** | 单击下载，正确 MIME 类型，UTF-8 文件名支持 |
| **编辑** | 全屏代码编辑器编辑文本文件，保存后直接写回服务器 |
| **管理** | 新建文件/文件夹、重命名、删除（带确认弹窗） |
| **国际化** | 中/英文切换，localStorage 记忆；新用户默认英文；唯一用户标识 |
| **主题** | 深色/浅色模式，跟随系统 `prefers-color-scheme`，手动切换可记忆 |
| **响应式** | 桌面端表格布局，700px 断点切换移动端卡片布局 |
| **安全** | 路径穿越防护、POST 大小限制（上传/写入 100 MB，元数据 64 KB）、标头转义 |

## 环境要求

### 服务器端（Android 手机）

- **Root 权限**（`su`）— 用于 iptables 端口转发和绑定辅助 IP
- **Python 3.8+** — 可通过 Termux、Magisk 模块或手动推送二进制安装
- **移动热点** 已开启

### 客户端（连接设备）

- 任意有浏览器的设备（手机/平板/电脑）
- 连接到手机热点 Wi-Fi

## 快速开始

### 1. 推送文件到手机

```bash
adb push server.py launch.sh stop.sh /data/local/tmp/
adb shell chmod +x /data/local/tmp/launch.sh /data/local/tmp/stop.sh
```

### 2. 打开热点

在手机上开启移动热点（设置 → 热点和网络共享 → WLAN 热点）。

### 3. 启动服务器

在手机上（通过 adb shell 或终端模拟器）：

```bash
su
sh /data/local/tmp/launch.sh
```

启动脚本会自动：
- 检测热点网卡和 IP 地址
- 在同子网随机选取辅助 IP（如 `192.168.43.172`）
- 配置 iptables 允许入站连接
- 在辅助 IP 上将 80 端口重定向到 6532
- 启动 Python 服务器

```
╔══════════════════════════════════════════════════════════╗
║  服务器已启动！访问地址：                                ║
║  http://192.168.43.172:6532                             ║
║  http://192.168.43.172  (80 端口自动转发)               ║
║  服务目录: /sdcard                                      ║
╚══════════════════════════════════════════════════════════╝
```

### 4. 客户端访问

在连接到手机热点的任意设备浏览器中，输入启动脚本显示的地址即可。

### 5. 停止服务器

```bash
sh /data/local/tmp/stop.sh
```

这会结束服务器进程、移除辅助 IP 别名并清理 iptables 规则。

## 无 Root 运行

如果没有 root 权限，也可以直接运行服务器（只是没有 iptables 和随机辅助 IP）：

```bash
python3 /data/local/tmp/server.py
```

服务器会监听所有网卡 (`0.0.0.0:6532`)。连接设备可通过手机热点 IP（通常 `192.168.43.1:6532`）访问。

## API 接口

所有 API 端点以 `/api` 开头。

| 方法 | 端点 | 说明 |
|------|------|------|
| `GET` | `/api/list?path=<路径>` | 列出目录内容 |
| `GET` | `/api/download?path=<路径>` | 下载文件 |
| `POST` | `/api/upload` | 上传文件（multipart 表单） |
| `POST` | `/api/write` | 创建或覆盖文件（JSON） |
| `POST` | `/api/delete` | 删除文件或目录 |
| `POST` | `/api/mkdir` | 创建目录 |
| `POST` | `/api/rename` | 重命名或移动文件/目录 |

### 返回格式

**成功**（列表）：
```json
{ "entries": [{ "name": "照片.jpg", "isdir": false, "size": 2048, "mtime": 1700000000 }] }
```

**成功**（写入/删除/创建/重命名/上传）：
```json
{ "ok": true }
```

**错误**：
```json
{ "error": "错误描述" }
```

## 架构

```
launch.sh                    stop.sh
───────────                  ─────────
│ Root 检查 │               │ 结束进程 │
│ 查找 Python│              │ 移除 IP  │
│ 检测网卡  │               │ 清理防火墙│
│ 随机 IP   │               ────────────
│ iptables  │
│ 启动服务器 │
└─────┬─────┘
      │
      ▼
  server.py
  ───────────
  Python HTTP 服务器 (端口 6532)
  │
  ├─ GET  /          → 内嵌单页前端
  ├─ GET  /api/*     → 文件操作
  └─ POST /api/*     → 数据变更
```

整个前端以 Python 原始字符串形式内嵌在 `server.py` 中，无需外部 HTML/CSS/JS 文件。单页应用通过统一的 `api()` 辅助函数发起请求，使用事件委托（data 属性）处理 DOM 交互。

### 前端设计

- **字体**：Bebas Neue（品牌标题）、Figtree（正文）、JetBrains Mono（数据/代码）
- **主题**：CSS 自定义属性配合 `[data-theme="dark"]` / `[data-theme="light"]`
- **国际化**：基于 `data-i18n` 属性的模板替换，`localStorage` 持久化
- **安全**：文件操作不使用内联 `onclick`，全部采用 `data-*` 属性 + 事件委托

## 常见问题

| 问题 | 解决方法 |
|------|----------|
| `找不到 Python` | 通过 Termux 安装（`pkg install python3`）或手动推送二进制 |
| `未检测到热点 IP` | 确保启动脚本前已**开启**移动热点 |
| `grep: Unknown option` | 当前版本已修复（改用 `sed`） |
| 下载含中文文件名时报错 | 当前版本已修复（使用 RFC 5987 `filename*=UTF-8''`） |
| 客户端无法访问 | 确认客户端连接的是手机热点而非移动数据 |
| 端口被占用 | `launch.sh` 会自动结束同端口的旧进程 |
