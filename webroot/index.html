⚡ FileBase

Android Wi-Fi File Server

Features
  • Browse files
  • Upload / Download
  • Edit text files
  • Dark / Light theme
  • No client install
  • i18n support
Quick Start

1. Install module via Magisk / KernelSU / APatch

2. Open WebUI from your root manager

3. Tap Start and connect to displayed IP

http://192.168.43.x:6532
CLI Commands
sh /data/adb/modules/filebase/action.sh start sh /data/adb/modules/filebase/action.sh status
📁 Open File Browser →
