About / Help

FileBase — Android File Server

Serve /sdcard over hotspot LAN. Browse, upload, download, edit files from any connected device.

Quick Start

  1. Install this module via Magisk / KernelSU / APatch.
  2. Open the WebUI from your root manager.
  3. Tap Start to launch the server.
  4. Connect to the displayed IP from another device.

CLI Commands

  • su -c 'sh /data/adb/modules/filebase/action.sh start'
  • su -c 'sh /data/adb/modules/filebase/action.sh stop'
  • su -c 'sh /data/adb/modules/filebase/action.sh status'

Log Levels

  • Info — Client IP + HTTP method + status code
  • Error — Only 4xx / 5xx responses
  • Debug — Timestamp, IP:port, method, full path
  • Off — No log file
