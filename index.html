Good to know

Questions, answered

Do I need root?
No. The standalone script runs as a normal app process and serves /sdcard. Root is only needed if you want the module integration or admin access to the whole filesystem.
Which root managers are supported?
Magisk, KernelSU and APatch. The module ships a WebUI panel that follows the KernelSU module guide, plus an action.sh that works from any manager's Action button.
Does anything leave my network?
No. FileBase binds to the hotspot interface and talks plain HTTP on the LAN. There is no telemetry, no cloud and no external asset — the whole UI is embedded in server.py.
Why is admin mode faster now?
It used to shell out to su, base64 and stat for every single entry. It now reads the directory directly and only escalates when a permission error actually happens.
Can I change the port or log level?
Yes. Set PORT and BIND_IP in the environment, or use the WebUI panel to switch between off / error / info / debug logging. Restart the server to apply.
Is it safe on a shared hotspot?
Every write is CSRF-checked, paths are resolved and confined to the root, uploads are size-limited and the editor refuses binaries. Still: treat the hotspot password as the real access control, and change the default admin password.
