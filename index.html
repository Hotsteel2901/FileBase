Everything you need

A full file manager in the browser

No client to install. Anyone on the hotspot gets a fast, responsive file manager.

Browse

Sortable columns, breadcrumb navigation and live filtering, tuned for touch.

Upload & download

Drag-and-drop with progress, multi-file upload and resumable downloads over HTTP Range.

Edit anywhere

Built-in code editor with a binary guard, so photos and videos are never corrupted.

Safe by default

Path-traversal protection, request size limits and CSRF checks on every write.

Root & admin mode

Optional admin login lifts the sandbox and exposes the whole filesystem.

One-tap control

Start and stop from your root manager's Action button or the built-in WebUI panel.

Quick start

1

Turn on the hotspot

Any device that joins it can reach the server.

2

Start FileBase

Tap the Action button, open the WebUI, or run the command below.

3

Open the address

The panel shows the exact URL, e.g. http://192.168.43.172:6532

# standalone
adb push server.py launch.sh stop.sh /data/local/tmp/
su -c 'sh /data/local/tmp/launch.sh'

# module (Magisk / KernelSU / APatch)
su -c 'sh /data/adb/modules/filebase/action.sh start'
